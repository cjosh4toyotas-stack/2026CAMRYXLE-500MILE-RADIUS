What every 2026 Camry XLE includes

Standard equipment on the XLE grade. Every unit on this page has all of this before any option or accessory is added.

Mechanical

  • Front-Wheel Drive (FWD)
  • Drive Mode Select (DMS) with Sport, Eco, Normal and EV modes
  • 2.5-Liter, 4-cylinder DOHC 16-valve, Variable Valve Timing-intelligence (VVT-i) with Variable Valve Timing-intelligence by Electric motor (VVT-iE) on the intake side, 184 hp @ 6000 rpm, 163 lb.-ft. @ 3600–5200 rpm

Exterior

  • 18-in. two-tone multi-spoke machined and black-finished wheels
  • Dual LED projector low beams
  • Dark metallic gray horizontal bar front grille
  • LED Daytime Running Lights (DRL)
  • Premium LED combination taillights
  • Chrome-finished window trim

Interior

  • 12.3-in. digital gauge cluster
  • Dual zone automatic climate control with air filter, humidity sensor and rear-seat vents
  • Leather
  • Heated front seats
  • Leather-trimmed heated tilt/telescopic steering wheel
  • Qi-compatible wireless charging with charge indicator light

Audio Multimedia

  • 12.3-in. Toyota Audio Multimedia touchscreen with USB-A media port, hands-free phone capability and music streaming via Bluetooth® wireless technology, SiriusXM® 3-month trial subscription
  • Wireless Android Auto™ compatibility
  • Wireless Apple CarPlay® compatibility
  • 6-speaker audio system

Connected Services

  • Remote Connect
  • Safety Connect®
  • Service Connect
  • Drive Connect
  • Wi-Fi Connect

Safety / Convenience

  • Toyota Safety Sense™ 3.0 (TSS 3.0)
  • Blind Spot Monitor (BSM) with Rear Cross-Traffic Alert (RCTA) and Safe Exit Alert (SEA)
  • Eight airbags

Factory options and packages

These are the factory-installed options that change what a given XLE has beyond standard equipment. Each unit above lists which of these it was built with, by code. Package MSRPs are already included in each unit's Total MSRP.

Code PR
$1,330
  • Panoramic glass roof with front power tilt/slide moonroof (removal of overhead sunglasses storage)

Premium Package

Code PM
$3,810
  • Panoramic glass roof with front power tilt/slide moonroof (removal of overhead sunglasses storage)
  • 9-speaker JBL® Premium Audio system
  • Ventilated front seats
  • 10-in. Head Up Display (HUD)
  • Digital Key capability
  • Rain-sensing windshield wipers
  • Driver's seat and outer-mirror memory
None of the units on this page were built with the Premium Package on its own; it is shown so the Premium Plus Package reads clearly.

Premium Plus Package

Code QP
$4,760
  • Everything in the Premium Package, plus:
  • Traffic Jam Assist (TJA)
  • Front Cross-Traffic Alert (FCTA)
  • Lane Change Assist (LCA)
  • Panoramic View Monitor
  • Front and Rear Parking Assist with Automatic Braking (PA w/AB)
  • Rear Cross-Traffic Braking (RCTB)
  • Driver Monitor Camera

Premium Paint (code PC) applies to Supersonic Red. All other codes on a unit are dealer- or port-installed accessories: floor liners, door edge guards, mudguards, wheel locks, paint protection and similar.
